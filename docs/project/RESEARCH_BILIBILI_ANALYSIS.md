# 需求调研：从 B 站 BV 链接分析影视/视频内容

调研日期：2026-11-19
状态：新增需求候选；未经授权的自动采集不可进入实现。
范围：官方公开资料与用户提及的本地 GGdown 工具；未调用 B 站接口、未读取 Cookie/凭据、未分析或下载视频。

## 1. 用户想法

输入一个 B 站 BV 链接，围绕单个影视/视频作品整理可获得的数据，例如作品元信息、点赞/投币/收藏/播放等互动指标，以及评论、弹幕，用于主题、情绪、关键词和讨论变化分析。用户提到 GGdown 的复制链接下载流程作为交互参考。

## 2. 本地参考软件观察

该工具具备媒体下载/处理能力。未审阅其源代码、说明文档或日志，也未读取下载媒体内容。因此只能把“粘贴链接”记为可参考的输入方式，不能据此确认其内部接口策略、合规授权或可复用实现。

MindOS Radar 是研究信息管理工具，不应因此引入视频下载器、媒体转码器或作品文件存储。

## 3. 官方平台能力与边界

- B 站开放平台的官方说明列有账号授权、用户管理、视频稿件管理和“数据开放”；页面称数据开放针对用户授权后的用户数据、稿件数据，并要求完成身份认证/审核后申请应用。[开放平台文档中心](https://open.bilibili.com/doc/)
- 开放平台的稿件数据管理隐私说明列出可披露给关联开发者的稿件指标，包括标题、发布时间、播放、点赞、评论、硬币、收藏、弹幕和分享数量。这类说明处于“关联 UP 主/关联账号授权”的服务背景，不能推导为任何人凭 BV 号即可查询任意视频数据。[开放平台稿件数据隐私说明](https://open.bilibili.com/agreement/privacy-policy)、[开发者服务协议](https://openhome.bilibili.com/agreement/developer-service)
- B 站用户使用协议 4.2.11 写明，未经事先明确书面许可，不得以机器人、蜘蛛、爬虫等自动程序或脚本获取平台服务、内容、数据。[用户使用协议](https://www.bilibili.com/opus/720866757074485248)
- 开放平台协议还要求开发者经过入驻/应用关联及授权流程，并限制开放平台数据的用途、披露和留存。[开放平台管理规范](https://openhome.bilibili.com/agreement/management-protocol)
- 本次查阅的官方资料没有确认：普通第三方应用是否能通过官方授权接口获取任意 BV 的原始评论全文、历史弹幕全文，或是否存在相应授权范围、配额和留存权利。不得把非官方接口、网页内部请求或第三方下载器行为当成官方 API 许可。

**调研结论：**工程上“链接解析、拉取公开页面数据、汇总互动文本”可能存在技术路径，但依当前官方条款，未取得平台事先明确书面许可前，不应以自动爬虫实现。可研究的合规路径是申请官方开放平台能力并严格限于获准关联账号/稿件与授权范围，或导入用户有权取得且适合本地分析的数据文件。对任意第三方作品的评论/弹幕采集目前是未确认能力，作为阻塞项处理。

## 4. 可考虑的产品范围

### 低风险候选 MVP（需先确认具体数据权利）

1. 粘贴 BV 链接，仅保存链接、BV 标识和用户填写的研究备注；不下载媒体。
2. 通过正式批准的开放平台授权读取关联 UP 主自己有权管理的稿件指标；字段、频率、存储期限均以实际获批范围为准。
3. 支持用户手动导入其有权导出的评论/弹幕数据文件；导入前预览字段、条数和敏感信息，默认本机保存，可限制保留期。
4. 对获准/导入的数据做去标识化后的词频、主题、时间趋势和抽样阅读；AI 仍需手动触发并遵守现有预算与隐私边界。

### 当前排除

- 对任意 BV 号自动爬取第三方视频的点赞/收藏/评论/弹幕或绕开登录、访问控制、验证码、风控和限流。
- 逆向/复用下载器的私有接口、登录 Cookie、签名算法或协议；批量下载、解密、提取或保存视频/音轨。
- 把公开视频可浏览等同于可以自动抓取、长期保存、汇总传播或交给外部模型处理。

## 5. 进入开发前置条件

1. 向 B 站开放平台确认并取得书面答复：应用入驻资质、获准主体/账号关系、目标字段是否包括原始评论和视频弹幕、API 配额、用途限制、展示/导出范围、保存期限及删除要求。
2. 明确功能仅针对自有/已授权作品，还是还包含第三方公开作品；后者必须有覆盖该用途的明确许可，不能仅凭账号登录或公开页面访问推定授权。
3. 评估评论与弹幕中的个人信息、用户生成内容和版权处理；定义数据最小化、默认本机处理、保留期、删除、导出和 AI 发送规则。
4. 获批后另行形成接口证据、数据字段映射、节流策略、失败状态、验收用例与变更范围，再决定是否开发；未获授权时只实现合规的手工导入路径。
